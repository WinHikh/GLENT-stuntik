# GLENT VPN PITBIKE STUNT — Godot 3D

Новая отдельная версия на Godot 4.3. Старый Unity-проект не удаляется.

## В прототипе
- 3D-арена в красно-чёрном стиле
- процедурная модель питбайка/райдера
- газ, тормоз, поворот, прыжок
- трамплины и три режима камеры
- экранные кнопки для телефона
- GitHub Actions для облачной сборки APK

## Сборка с телефона
1. Создай новый репозиторий GitHub `glent-vpn-pitbike-godot`.
2. Загрузи содержимое этой папки в корень репозитория (не ZIP-файл целиком).
3. Открой Actions и разреши запуск workflows, если GitHub попросит.
4. Выбери **Build Android APK** → **Run workflow**.
5. После завершения открой запуск → **Artifacts** → `GLENT-VPN-Pitbike-APK`.

## Важно
Это стартовый прототип, а не готовый релиз. Workflow и экспорт Android могут потребовать настройки; если сборка упадёт, пришли скриншот ошибки из Actions. Unity-версия остаётся отдельной для будущего продолжения.
